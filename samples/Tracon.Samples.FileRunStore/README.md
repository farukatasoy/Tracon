# File run store sample

This sample implements `IRunStore` and `IRunScoreStore` with file-backed run data.
Its sibling test project derives from the public contract suites in
`Tracon.Testing.Contracts.Xunit`.

The projects reference packed NuGet artifacts, not Tracon source projects. Run them
through the repository's release gate as described in [`../README.md`](../README.md).
