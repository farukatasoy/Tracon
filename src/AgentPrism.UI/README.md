# AgentPrism.UI

AgentPrismUI - gomulu yonetim arayuzu.

React + TypeScript ile yazilmis tek sayfa uygulama. Assembly icine gomulur ve `/agentprism` altindan sunulur. Tuketici projede hicbir JavaScript bagimliligi olusturmaz.

Ekranlar: Agents, Playground, Sessions, Runs, Tools, Models, Settings.

## Kurulum

```bash
dotnet add package AgentPrism.UI
```
