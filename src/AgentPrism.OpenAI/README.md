# AgentPrism.OpenAI

AgentPrism icin OpenAI saglayici adaptoru.

Model katalogu, `IChatClient` uretimi ve OpenAI'a ozgu calistirma secenekleri.

```csharp
builder.AddAgentPrism()
       .UseOpenAI(apiKey);
```

## Kurulum

```bash
dotnet add package AgentPrism.OpenAI
```
