  <Card title="One call, whole control plane" icon="rocket">
    `MapAgentPrism` adds 143 HTTP operations and an embedded management console to an
    existing application. Nothing is exposed to the network until you say so.
  </Card>
  <Card title="Every run is recorded" icon="approve-check">
    There is no code path that runs an agent without writing a run row. Status,
    timings, tokens, cost, tool calls, and the event stream — all queryable.
  </Card>
  <Card title="No database required" icon="setting">
    Configure nothing and every store runs in memory. Add PostgreSQL, SQL Server, or
    SQLite when the runs need to outlive the process.
  </Card>
  <Card title="MAF, not a wrapper" icon="puzzle">
    `AIAgent`, `AgentSession`, and `AIFunction` are used directly and appear in the
    public API as themselves. Anything you know how to do with MAF keeps working.
  </Card>
</CardGrid>

## Thirty seconds

<Code
  lang="csharp"
  title="Program.cs"
  code={`var builder = WebApplication.CreateBuilder(args);

builder.AddAgentPrism()
       .UseOpenAI(builder.Configuration["OpenAI:ApiKey"]!)
       .UseUI();

var app = builder.Build();

app.MapAgentPrism("/agentprism");
app.Run();`}
/>

Run it and open `/agentprism`. Create an agent, talk to it in the playground, then
open the run and read it back event by event.
