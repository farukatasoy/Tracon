## No abstraction over MAF.

Keep MAF's `AIAgent`, `AgentSession`, `ChatMessage`, and `AIFunction`. Tracon adds
catalogs, policies, persistence, inspection, and HTTP access around those objects.
There is no parallel agent type hierarchy to adopt. The
[architecture page](/concepts/) draws the layers and the dependency direction.

## Registration is C#. A tool is a method.

Mark a method and a source generator registers it at build time. There is no
reflection, no tool manifest, and no AOT warning. The console selects from the tools
you compiled; it can never write tool code.

<Code lang="csharp" title="Tools/OrderTools.cs" code={`using Tracon;

internal class OrderTools
{
    [TraconTool("get_order_status", "Returns the shipping status of an order.")]
    public static string GetOrderStatus(string orderId)
        => $"Order {orderId} has shipped. Estimated delivery: 2 days.";
}`} />

<Code lang="csharp" title="Program.cs" code={`using Tracon;

var builder = WebApplication.CreateBuilder(args);

var tracon = builder.AddTracon()
    .AddGeneratedTools()
    .UsePostgreSql(builder.Configuration.GetConnectionString("Tracon")!)
    .UseOpenAI(builder.Configuration["OpenAI:ApiKey"]!);

tracon.AddAgent(new AgentDefinition
{
    Name = "support",
    Instructions = "Answer order questions. Use a tool for anything about an order.",
    Model = new ModelBinding
    {
        Provider = OpenAIProviderNames.ChatCompletions,
        Model = builder.Configuration["OpenAI:Model"]!,
    },
    ToolNames = ["get_order_status"],
});

var app = builder.Build();
app.MapTracon("/tracon");
app.Run();`} />

An agent is data, so changing one is a write rather than a deployment. Every save
appends a version, a rollback writes the old content forward as a new version, and
the rollback is itself audited. See [versions and rollback](/concepts/agents/#versions).

Storage starts in memory and the host still starts without a provider key, so each
call above is a choice rather than a requirement. The packages are published as
`1.0.0-preview.2`, so install them with `--prerelease`: there is no stable version
yet, and a command without the flag ends in `NU1103`.

## The console ships in the assembly.

The control plane above runs without a user interface. Add `Tracon.UI` and one more
call — `UseUI()` on the same builder — to embed the console in your host. It reads
the same management API that your own clients can call. The consuming application
does not need Node.js or a JavaScript build to serve it.
