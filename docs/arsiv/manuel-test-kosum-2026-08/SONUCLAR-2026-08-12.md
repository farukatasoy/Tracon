### HATA-001 — `AutoApplyMigrations=false` altında, boş şemaya karşı, A2A/MCP açıkken uygulama kendini kapatıyor

- **Case:** MT-PG-025 (ayrıca MT-PG-034, MT-PG-051, MT-PG-052 aynı kök nedenden bloklandı/tetiklendi)
- **Önem:** Kritik (dosyada Yüksek işaretliydi; gözlenen etki nedeniyle yükseltilmesi önerilir)
- **İzlek:** B
- **Ortam:** macOS arm64 · net10 · PostgreSQL · `echo` (model sağlayıcı ilgisiz)

**Beklenen**
`AutoApplyMigrations=false` iken boş şemaya karşı başlatılan uygulama normal
açılır, `/health` Unhealthy döner, hizmet vermeye devam eder — sorumluluk
operatöre kalır (K-354).

**Gerçekleşen**
Uygulama `Now listening` yazdıktan birkaç saniye sonra kendini kapatıyor.
`A2AApprovalGuardFilter` (ve aynı desenle `McpApprovalGuardFilter`) arka plan
denetimi `SchemaReadyGate` açılır açılmaz `IAgentCatalog.ListAsync()` çağırıyor;
`AutoApplyMigrations=false` iken `SchemaReadyGate.MarkReady()` migration
BEKLEMEDEN hemen çağrılıyor (bilerek — "sorumluluk operatöre kalır" yorumu).
Var olmayan `agentprism.agent_definitions` tablosuna çarpan sorgu `catch
(Exception)` → `LogCritical` + `lifetime.StopApplication()` ile karşılanıyor.
İki bağımsız denemede TUTARLI biçimde tekrar üretildi.

**Yeniden üretme**
1. `docker exec -i ap-pg psql -U postgres -d agentprism -c "DROP SCHEMA IF EXISTS agentprism CASCADE;"`
2. `dotnet user-secrets set "AgentPrism:PostgreSql:AutoApplyMigrations" "false"`
3. `cd samples/AgentPrism.Api && dotnet run` (varsayılan `UseA2A`/`UseMcpServer` açık örnek uygulama)
4. Birkaç saniye içinde `crit: AgentPrism.A2AApprovalGuardFilter[0]` + `Application is shutting down...` görülür.

**Kanıt**
- `docs/manuel-test/03-KALICILIK-POSTGRESQL.md` `MT-PG-025`'in "Gerçek sonuç" alanı (tam log alıntısı).
- Kaynak: `src/AgentPrism.AspNetCore/A2A/A2AApprovalGuardFilter.cs:67-78`,
  `src/AgentPrism.Abstractions/Diagnostics/SchemaReadyGate.cs:51-59`.

**Kapsam**
Yalnız bu case değil — `MT-PG-034` (iki sağlayıcı kayıtlıyken kazanan tarafın
migrasyonu geç biterse AYNI mekanizmayla çöküyor) ve `MT-PG-051`/`MT-PG-052`
(bu case'in ön koşulunu paylaştıkları için hiç koşulamadılar) doğrudan
etkileniyor. `AutoApplyMigrations=false` belgelenen sözleşmesi, A2A veya MCP

### HATA-005 — Gövdesinde eksik `required` alan veya geçersiz enum değeri olan istekler 400 yerine 500 döndürüyor (sistemik)

- **Case:** MT-CORE-009 (adım 2), MT-CORE-022 (c1, c2), MT-CORE-006 (yanlış alan adıyla kayıt denemesi)
- **Önem:** Yüksek (dosyada tek tek Orta/Yüksek işaretliydi; sistemik oluşu nedeniyle birlikte değerlendirilmeli)
- **İzlek:** B
- **Ortam:** macOS arm64 · net10 · PostgreSQL (izole)

**Beklenen**
Hiçbir istekte 500 dönmez; geçersiz/eksik istek gövdesi anlaşılır bir 400 ile
karşılanır (proje ilkesi: "hiçbir istekte 500 dönmez").

**Gerçekleşen**
Üç bağımsız senaryoda genel bir `500 ProblemDetails` ("An error occurred while
processing your request.") döndü:
1. `POST /api/agents/validate` gövdesinde `name` alanı hiç yoksa (MT-CORE-009/2).
2. `compaction.strategy` geçersiz veya yazım hatalı bir enum değeri taşıyorsa
   (MT-CORE-022 c1: "Summarize" yerine doğrusu "Summarization"; c2: bilerek
   geçersiz).
3. `PUT /api/mcp-servers/{ad}` gövdesinde `required` `Endpoint` alanı yerine
   yanlış bir alan adı (`url`) gönderilirse.

Kök neden (sunucu logundan doğrulandı, üçünde de aynı desen):
`System.Text.Json`, eksik `required` özellik veya tanınmayan enum değeri için
`JsonException` fırlatıyor → ASP.NET Core bunu `BadHttpRequestException`'a
sarıyor → uygulamanın genel exception handler'ı bunu 400 yerine 500
ProblemDetails'e çeviriyor. Bu, tek bir endpoint'e özgü değil — gövdesinde
`required` üye veya enum tipi alan taşıyan HERHANGİ bir endpoint aynı riski
taşıyor.

Ayrıca MT-CORE-022 c2 için ek bir sonuç: doküman'ın "mesaj bilinmeyen strateji
adını aynen taşır" beklentisi HTTP API üzerinden hiçbir zaman gerçekleşemez —
validator/compiler mantığına hiç ulaşılmadan JSON ayrıştırma katmanında daha
erken patlıyor.

**Yeniden üretme**
```bash
curl -s -w "\nHTTP:%{http_code}\n" -X POST "$APU/api/agents/validate" -H "$APB" \
  -H "content-type: application/json" -d '{ "model": { "provider": "echo", "model": "echo-1" } }'
# HTTP:500 (beklenen: 400)

curl -s -w "\nHTTP:%{http_code}\n" -X POST "$APU/api/agents/validate" -H "$APB" \
  -H "content-type: application/json" \
  -d '{"name":"c","model":{"provider":"echo","model":"echo-1"},"compaction":{"strategy":"BoyleBirSeyYok","triggerTokens":1000}}'
# HTTP:500 (beklenen: 400 + valid:false)
```

**Kanıt**
- `docs/manuel-test/02-CEKIRDEK-VE-KATALOG.md` `MT-CORE-009`, `MT-CORE-022`,
  `MT-CORE-006`'nın "Gerçek sonuç" alanları (tam istisna yığın izleri dahil).

**Kapsam**
Genel bir JSON gövde ayrıştırma sınırı sorunu; `07-HTTP-YONETIM-API.md`
koşumunda diğer endpoint'lere de yayılıp yayılmadığı ayrıca doğrulanmalı.
