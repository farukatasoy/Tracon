### F-598 · `ModelBinding` örnekleme ve tool döngüsü alanları (C-03)

**Kanıt seviyesi:** Ölçüldü — gerçek host probu (uzantının `Seed`/`TopK`/`StopSequences`/`ToolMode`/`FrequencyPenalty`/`AllowMultipleToolCalls`'u sağlayıcıya ulaştı; `Reasoning.Output` `400`), `AgentDefinitionCompiler.ChatOptions.cs:147-170`, `ModelProviderRegistry.cs:405-418`, MEAI Responses `reasoning.summary` eşlemesi (decompile), `OpenAIProviderNames.SupportedSettings` boş.
**Değer:** Tanım örneklemeyi ve tool döngüsünü veriyle seçer; OpenAI akıl yürütme özeti açılır; `TerminateOnUnknownCalls` önbellek yorumundaki tool yetki açığını kapatabilir (`TraconResponseCachingChatClient.cs:25`).
**Genellik:** İlk ilke: model ayarı tanımın işidir; bugün yalnız uzantıyla (kod) ve tanım sürümüne girmeden ayarlanır. Her sağlayıcı tüketicisi.
**Mercek:** 1, 5, 7, 8.
**Hazırlık:** MEAI alanları kararlı; K-034 sağlayıcı desteği deseni hazır.
**Maliyet:** `ModelBinding` public alanları, doğrulayıcı, konsol, TS istemcisi; JSON payload (migration yok, K-1031 `?` kuralı).
**Risk:** Alan tanıma geçince guard satırı `Free` → `Protected` (K-1029); unutulursa uzantı tanımı ezer.
**Bağımlılık:** K-1039 (run başına yol kapandı).
**Ekosistem (2026-10-20):** MEAI 10.11 `ChatOptions` 20 üye; OpenAI Responses `reasoning.summary`, Anthropic `thinking` (ProviderSettings).
**Karşı görüş:** Alanların çoğu sağlayıcıya özgüdür (`TopK` OpenAI'da yok); her alan için destek matrisi ve "desteklenmez" hatası gerekir, yoksa sessiz düşme olur (K-208).

### F-599 · Alt agent tek çağrı modu (C-04)

**Kanıt seviyesi:** Ölçüldü (okuma) — `AsAIFunction` (MAF decompile) agent'ı `RunAsync(query, session, AgentRunOptions{…})` ile çağırır; `ChildAgentInvoker.cs:197-213` ağaç bilgisini `TraconRunContext`'ten alır. `BackgroundAgentsProvider` 6 tool verir.
**Değer:** Tek çağrılık alt agent işi üç tool turu yerine bir tur harcar (token ve gecikme).
**Genellik:** Alt agent kullanan her tüketici.
**Mercek:** 5, 8.
**Hazırlık:** MAF hazır; sarmalayıcı hazır.
**Maliyet:** `SubAgentSettings`'e çağrı modu alanı, derleyici dalı, doğrulayıcı.
**Risk:** Senkron çağrı ebeveynin tool zaman aşımıyla çakışır; bekleme sınırı tek kaynaktan gelmeli.
**Bağımlılık:** —
**Ekosistem (2026-10-20):** MAF `AsAIFunction` 1.16'dan beri.
**Karşı görüş:** Model paralel `start_task` ile aynı turu verimli kullanabilir; kazancı ölçmeden alan eklemek konfigürasyon yüzeyini büyütür. Önce token farkı ölçülmeli.

### F-600 · Çalışan run'a mesaj (C-07)

**Kanıt seviyesi:** Ölçüldü — §0 #26 (gerçek host + düz MAF kontrolü).
**Değer:** Uzun harness run'ını durdurmadan yönlendirmek (steering).
**Genellik:** Uzun koşan agent işletenler; MAF'ın 1.16'dan beri sunduğu yetenek.
**Mercek:** 2, 6.
**Hazırlık:** MAF katmanı hazır; Tracon'da döngü içi yuva yok.
**Maliyet:** F-594 yuvası + HTTP ucu (kiracı, rol, denetim) + run olayı + kuyruklu run'da kira.
**Risk:** İki `MessageInjectingChatClient` aynı `StateBag` anahtarını ayrı kilitle paylaşır; tek örnek kurulmalı.
**Bağımlılık:** F-594.
**Ekosistem (2026-10-20):** MAF `EnableMessageInjection` + `RequirePerServiceCallChatHistoryPersistence` birlikte önerilir.
**Karşı görüş:** Talep ölçülmedi; tüketici run'ı iptal edip yeni mesajla yeniden başlatabilir. F-594 gelmeden yapılamaz.

### F-603 · Adlı hosted tool'lar (C-12 a)

**Kanıt seviyesi:** Ölçüldü — gerçek OpenAI tel probu (2026-10-20, `MAF-KAPSAMA.md` §8.0 C-12): `store=false` engel değil; ücret `UsageDetails`'te yok; Chat Completions hosted code interpreter'ı sessizce düşürür.
**Değer:** Code interpreter, file search ve web search tanımda adla açılır; ücret run maliyetine girer. Harness web search'ün bugün görünmeyen ücreti (K-892) de sayılır.
**Genellik:** OpenAI Responses kullanan her tüketici.
**Mercek:** 1, 6, 8.
**Hazırlık:** MEAI hosted tool tipleri hazır; içerik kaydı Faz 223'te.
**Maliyet:** Kodla adlı kayıt + `ToolNames` seçimi; yüzey doğrulaması (derleme hatası); fiyat tablosu (çağrı ve konteyner); file search içerik tipi.
**Risk:** Code interpreter konteyneri oturum başına ücretlenir, çağrı başına değil; yanlış fiyat birimi kotayı bozar (K-483 sınıfı).
**Bağımlılık:** —
**Ekosistem (2026-10-20):** OpenAI Responses hosted tool'ları; image generation sunulmaz (Tracon `generate_image`).
**Karşı görüş:** Code interpreter sağlayıcının konteynerinde kod koşturur; kiracı verisinin sağlayıcı konteynerine çıkışı bir uyum kararıdır ve tanımda adla açılması yetmeyebilir.

### F-604 · Hosted MCP sunucusu (C-12 b)

**Kanıt seviyesi:** Ölçüldü — tel probu: onay (`AlwaysRequire`) `store=false` ile JSON'dan dönen istekle çalışır; Tracon onay yolu `McpServerToolCallContent`'i "unknown" yazar (`ToolApprovalResolver.cs:91,197`).
**Değer:** Tracon'dan geçmeden sağlayıcı tarafında MCP tool'u.
**Genellik:** OpenAI kullanan, MCP sunucusu olan ekipler.
**Mercek:** 6.
**Hazırlık:** MEAI `HostedMcpServerTool` hazır.
**Maliyet:** `secret` adla (K-059), adres izin listesi, onay eşlemesi, kural yazımı.
**Risk:** OpenAI sunucuyu kendi bulutundan çağırır; Tracon egress'i, MCP OAuth'u ve tool zinciri devre dışıdır. Kiracı verisi üçüncü tarafa Tracon'un görmediği yoldan gider.
**Bağımlılık:** F-603.
**Ekosistem (2026-10-20):** OpenAI remote MCP; DeepWiki ile ölçüldü.
**Karşı görüş:** Tracon'un kendi MCP istemcisi (`Tracon.Mcp`) aynı işi yönetimle yapar; hosted MCP onu atlatır. Yalnız gecikme ya da sağlayıcıya özgü bağlayıcı (connector) gerekiyorsa değer taşır.

**Karşı görüş:** (a) küçük ve değerli; (b) ve (c) talep ölçülmeden büyük. Faz planlama (a) ile başlamalı.
